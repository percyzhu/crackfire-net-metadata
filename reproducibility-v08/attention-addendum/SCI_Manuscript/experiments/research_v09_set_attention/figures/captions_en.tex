\paragraph{Exploratory three-model comparison.}
Equal-case mean absolute error (MAE) for the capacity-matched independent-node set model, the sum-aggregation GNN and the interaction-capable set-attention control across all 12 frozen evaluation protocols. The attention control was specified after inspection of the original seven-model results and is therefore an exploratory extension. Small points denote five training seeds, large points their mean, and whiskers one sample standard deviation; the whiskers are not confidence intervals. The label $n$ denotes independent test geometries, not five times that count. Each error is averaged over the 61 archived response-index samples before averaging over cases. Panels use the same linear scale, with values displayed in $10^{-3}$ units. The 120 existing comparator runs are reused without reselection; 60 attention runs are newly trained. The original 420-run evidence remains the primary comparison.

\paragraph{Exploratory paired representation effects.}
Paired MAE differences for matched set minus set attention and sum GNN minus set attention across all 12 frozen protocols. Positive values favor attention and negative values favor the named comparator. Points average the paired case errors over five seeds. Whiskers are percentile 95\% intervals from the fixed 5,000-replicate crossed geometry--seed bootstrap, which retains complete time histories and pairs the same resamples across models. These approximate intervals reflect the limited five-seed experiment; they are not predictive uncertainty intervals or causal estimates of the effect of message passing. All protocols and both signs are retained. Values are displayed in $10^{-3}$ response-index units. The extension supplements the original seven-model results and does not alter their topology-stress or engineering-screening conclusions.
