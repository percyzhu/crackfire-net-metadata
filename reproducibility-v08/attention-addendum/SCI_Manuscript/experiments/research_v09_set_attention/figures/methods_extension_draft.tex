\subsection{Exploratory control for interactions between cracks}
The original comparison included an independent-node set model with approximately the same parameter count as the GNN. After inspecting the complete seven-model results, we identified that parameter matching alone did not provide a set-based control capable of interactions between cracks. We therefore specified a separate exploratory extension before its first optimization step. Its results supplement the original experiment and are not presented as part of the original prespecification.

The additional model retains the original 11-component node inputs, three global features, 61-by-four prescribed-exposure inputs, temporal branch and response decoder. After the original 11-to-64 node encoder, four shared, position-free self-attention blocks process the cracks. Each block uses four attention heads of dimension 16, pre-layer normalization, residual connections and a ReLU feed-forward layer of width 104. Padding keys are masked, padding outputs are removed, and the valid node representations are averaged before the unchanged global fusion. The model uses no raw edge features or positional encoding and has no dropout. It has 194,273 trainable parameters, compared with 194,177 in the sum GNN; the feed-forward width was selected analytically for this parameter budget, without an accuracy search. The attention operation includes each node's own key and value, whereas the graph representation has no self-edge and uses residual updates. This declared architectural difference is retained in interpretation.

The extension uses the same 997 archived targets, 12 data splits, five seeds, AdamW configuration, batch size of 32, maximum of 300 epochs, patience of 50, gradient clipping and cosine learning-rate schedule as the original experiment. Checkpoints are selected by the earliest minimum validation mean squared error. All 60 new runs are retained, and their two fixed comparator groups are the original 60 capacity-matched set runs and 60 sum-GNN runs. The two exploratory effects are matched-set MAE minus attention MAE and sum-GNN MAE minus attention MAE; positive values favor attention. We retain the original 5,000-replicate geometry-only, seed-only and crossed paired-bootstrap procedures for MAE, and the original 1,000-replicate secondary engineering-proxy procedures with their event, censoring and undefined-denominator rules. A geometry remains the independent case unit; five seeds do not multiply the number of independent geometries.

Software checks using real training inputs verified finite forward and backward calculations, nonzero cross-node interaction gradients, padding masks, invariance to node and batch order within floating-point precision, and rejection outside the declared one-to-fifteen-crack input range. The model ignores the supplied edge tensors by construction; invariance to their removal does not demonstrate learned robustness to changed connectivity. Likewise, differences among these selected architectures do not isolate a causal benefit of interactions or establish successful transfer to arbitrary graph topologies. The separately measured original seven-model inference costs are not estimates of this additional model's latency.
