# 主线LCRO的可读性修订v3

原v2已成功渲染、无画布文字越界；真实视觉检查发现Linear族的宽区间使其他协议的较小差值在全量线性尺度中难以辨认。根据用户事先明确的1–8到9–15裂缝数量外推主线，并经根任务确认，在同一CI图上方增加两项LCRO的线性放大视图；下方继续保留全12协议及完整区间。两组轴分别明确标记expanded/full linear scale，不截断、不删样本、不改变任何均值、区间或颜色方向，也没有重新计算统计。

图数仍为两张。MAE图继续用180×136mm，CI图为180×174mm。原生成器及v1失败、v2成功输出均保留；v3单独输出complete_reviewed_v3。此为版式修订，不是新的模型或实验；最终还需视觉检查和独立数字核对。
