# Full v08 local reproducibility package contract

This new package complements the sealed `deliverables/EAAI_reproducibility_v08_working` package. It never modifies that earlier directory. Preparing the builder is not a completed package or manuscript acceptance.

The complete local package contains the 997 small learning tensors and unchanged manifest, all 12 frozen splits, the original 420-run plan and 12 byte-identical frozen sources, the Windows I/O recovery wrapper/amendment and preserved recovery evidence, all 420 best checkpoints, their complete and declared sparse predictions, run metadata/results/status/training logs, final aggregate tables/replay records, and all protocol-level engineering/statistical independent reviews. Source dependencies and package files have explicit SHA256 identities. The numerical input and archived-response interpretation remain unchanged.

The first gate requires all 12 protocols × 35, the final 420 computational-replay report, and every protocol's engineering CI and independent results review before opening score payloads or collecting run contents. Later validation binds actual checkpoint/prediction bytes, preserves CPU-backend differences and requires the original GPU identity record where applicable. It also binds sparse views to the same checkpoint and preserves the recovery chain. Optional later figure, timing and manuscript files are not silently claimed as complete; this minimum package covers the complete AI research evidence. Their release can be a separately versioned supplement.

The original plan retains its absolute historical paths and original SHA. A separate `relocation_map.json` maps exactly the two dataset/run roots and 12 split paths to package-relative locations; no new plan is passed off as the original. Runtime scripts resolve from their own directory, never the original D drive or current working directory. The inference entry supports all packaged protocol/model/seed checkpoints. The default diagnostic is the predeclared IID GNN seed42; it is not selected for best accuracy. CPU comparisons retain the original 3e-6 diagnostic threshold. CPU variation is reported, never converted into a claimed pass for all420; optional CUDA identity testing requires exact saved outputs and does not establish portability to another GPU.

The result verifier hashes every packaged source/file, checks all saved reference/ID/time bindings and recomputes all420 complete-view plus360 sparse-view metrics. Optional primary bootstrap recomputation uses the preserved statistics implementation and declared 5000 repetitions. Inference, saved-result arithmetic and new training are distinct: no new training is performed or claimed. A moved-directory inference check tests only the explicitly reported checkpoint/rules.

Exclude original FE meshes, ODBs, full temperature fields, raw large Abaqus archives, dependency binaries, duplicate ZIPs and unrelated documents. Manifest references to these original data remain historical provenance; this package cannot regenerate the FE or original scalar extraction from absent fields. No upload, public release or new license is selected. Default packaging creates one new directory only; it refuses existing destinations and the sealed earlier package. It preflights real free disk space and retains any interrupted staging directory rather than deleting evidence.

All420 weights are feasible: preliminary stat-only inspection found 393 current checkpoints occupying 221,570,660 bytes; a fixed-architecture estimate for420 is 237,173,760 bytes (226.2 MiB). This estimate is replaced by actual complete-package byte counts at build time.


Companion evidence addition, 7 September 2026: the builder also preserves the figure/table sources and saved artifacts, and the inference timing directory, available at build time. The explicit companion inventory lists each included file. Their individual QA records state completion; the package relocation checks do not claim to regenerate every figure or remeasure latency. Recorded historical paths remain provenance, and a separately adapted execution interface may be needed to rerun these companion generators outside the original workspace. The portable learning-data, prediction and result-arithmetic interface is unchanged.
